# 🗞️ Issue #015: The Load-Bearing Repos: Giving Thanks to the Code Holding Up the Internet

![The Terminal Thursday](https://images.vialoops.com/cmpfndk6x026w0jvslad39ftq/cmv8yi3q00f3w0j044w2njxiz.jpg)

It's Thanksgiving week in the US, so this issue is a thank-you note to code most of us never think about. xkcd's "Dependency" draws modern infrastructure balanced on one thin block that some random person in Nebraska maintains, and every engineer can name their own. The 2024 xz backdoor showed the risk: an attacker spent over two years earning maintainer trust. That's no reason to blame maintainers, and a strong one to help them. So: three tools to thank, twelve more on the Radar, and ways to chip in at the end.

Grab your coffee. Open your terminal. Let's start hacking.

## 🔬 The Sandbox: 3 Projects I Tested This Week

### 1. curl 🌐 *(Data Transfer)*

![curl](https://images.vialoops.com/cmpfndk6x026w0jvslad39ftq/cmw1w1o5n2sml0jyo6rsu1fwp.png)

**What is it?** curl is a command-line tool for moving data with URLs, built on libcurl, the C library that does the actual work; its README lists 25 protocols, from HTTP and FTP to MQTT and SFTP. The project's history page traces it to HttpGet 0.1, a small tool Rafael Sagula released in November 1996, which Daniel Stenberg took over and extended, and which became curl with the release of curl 4 in March 1998. It is distributed under an MIT-like license, and curl's governance page defines a maintainer as a project volunteer with the right to merge changes.

**Why you should care:**  
When a request misbehaves, curl takes your application out of the picture: `-v` prints verbose transfer details, `-I` fetches headers only, and `--resolve` overrides DNS for one host and port, which the manual calls an `/etc/hosts` alternative on the command line. The first line of `curl --version` names the third-party libraries linked into your build, such as the TLS library and zlib, so one command shows how many other projects hold curl up. The project's bug-reporting page also says exactly what to include: your version and OS, what you expected, and how to repeat the problem.

**My Rating:** Handshake Everywhere 4.9/5 ⭐  
**Website:** [github.com/curl/curl](https://github.com/curl/curl)

**💻 Get Started:**

```
curl --version | head -n 1 && curl -sI https://curl.se | head -n 1
```

### 2. jq 🔎 *(JSON Processor)*

![jq](https://images.vialoops.com/cmpfndk6x026w0jvslad39ftq/cmw1w1pho2q600jy77p6pgq74.png)

**What is it?** jq is a command-line JSON processor that its homepage describes as sed for JSON data: you write a short filter, and it slices, maps and reshapes structured input. It is written in portable C with zero runtime dependencies, so a single binary can be copied to another machine of the same type, and it is MIT-licensed. Stephen Dolan created it (the repository dates to 2012), and after a five-year gap between releases, a new group of maintainers moved the project to the jqlang GitHub organization in 2023 and shipped jq 1.7.

**Why you should care:**  
Pipe any JSON-speaking command into it: `-r` prints strings without quotes, `-n` runs a filter with no input at all, and `$ENV` exposes your environment variables as an object, which is all the Get Started line below needs. The project's own story is the second reason to care, because the 1.7 release notes open with the five-year hiatus and thank the new owners, admins and maintainers who got the long-awaited release out. That is what keeping a load-bearing tool alive looks like: new people taking on the CI, documentation and release chores.

**My Rating:** Second-Wind Filter 4.8/5 ⭐  
**Website:** [github.com/jqlang/jq](https://github.com/jqlang/jq)

**💻 Get Started:**

```
brew install jq && jq -nr '$ENV.PATH | split(":")[]'
```

### 3. SQLite 🗄️ *(Embedded Database)*

![SQLite](https://images.vialoops.com/cmpfndk6x026w0jvslad39ftq/cmw1w1qwa2smt0jyrfizygcyd.png)

**What is it?** SQLite is an in-process C library that implements a self-contained, serverless, zero-configuration, transactional SQL database engine: there is no server process, and a complete database with tables, indices, triggers and views lives in a single ordinary disk file. The source code is in the public domain. One accuracy note: sqlite/sqlite on GitHub is an official Git mirror, and its README says development happens in Fossil, the version control system written to support SQLite, at sqlite.org/src.

**Why you should care:**  
The file format is cross-platform, so a database copies cleanly between 32-bit and 64-bit systems or between big-endian and little-endian ones, and the project says SQLite is likely used more than all other database engines combined, found in every Android device, iPhone, Mac and Windows 10/11 install and every Firefox, Chrome and Safari browser. A team on three continents writes it, and the source files open with a blessing in place of a legal notice: "May you share freely, never taking more than you give." For bugs, use the project's forum; it does not accept patches without a public-domain affidavit, so a precise report is the practical way to help.

**My Rating:** Single-File Bedrock 4.9/5 ⭐  
**Website:** [github.com/sqlite/sqlite](https://github.com/sqlite/sqlite)

**💻 Get Started:**

```
sqlite3 ttt.db "create table t(x);" && ls -l ttt.db
```

## ☕ The Curious Non-Dev: No Code Required

**Why does so much of the internet depend on a handful of volunteers?**

Think of the pipes inside a city's walls. Nobody designs a new fitting for every house; everyone buys the standard one because it connects to everything else. Software works the same way for solved problems like compressing a file, reading a time zone or opening a secure connection: one good library gets reused everywhere, and open-source licenses let anyone do that without paying or asking. A 2024 Harvard Business School working paper put the supply-side value of widely used open source (the cost of building it once) at $4.15 billion, the demand-side value (what every company using it would pay to replace it) at $8.8 trillion, and found that over 95% of that demand-side value comes from about 5% of developers.

Who are those developers? In Tidelift's 2024 survey, 60% of the more than 400 maintainers who answered called themselves unpaid hobbyists, and only 12% earned most or all of their income from maintenance. Funding does exist: SQLite has a consortium of member companies, and in 2026 the City of Munich began paying libexpat's maintainer for up to six months. But think of the plumbing again. A water utility meters every household and sends a bill; nothing meters a library, so no bill goes out. That mismatch, not carelessness or villainy, is how load-bearing code ends up resting on a handful of people.

## 📡 The Radar: 12 More Load-Bearing Repos to Thank This Weekend

### 🧱 Foundations Under Everything

1. [madler/zlib](https://github.com/madler/zlib) (~7.2k Stars) - Jean-loup Gailly and Mark Adler's compression library, copyrighted since 1995, implements the zlib, deflate and gzip formats, and its README still asks volunteers to write the man pages.
2. [openssl/openssl](https://github.com/openssl/openssl) (~31.1k Stars) - A toolkit for TLS, DTLS and QUIC plus a general-purpose crypto library, descended from Eric Young and Tim Hudson's SSLeay and licensed under Apache 2.0.
3. [libexpat/libexpat](https://github.com/libexpat/libexpat) (~1.4k Stars) - A C99 streaming XML parser started by James Clark in 1997 under an MIT-style license; in 2026 the City of Munich began funding its maintainer for up to six months.
4. [tukaani-project/xz](https://github.com/tukaani-project/xz) (~1.7k Stars) - XZ Utils, the liblzma library and xz tool, whose LZMA2 compression the project says makes typical files about 30% smaller than gzip; its 5.6.0 and 5.6.1 tarballs carried the 2024 backdoor.

### 🕰️ Time, Text & Pixels

5. [eggert/tz](https://github.com/eggert/tz) (~1.9k Stars) - The mostly public-domain time zone database behind Python's zoneinfo, updated as governments change their clocks, sometimes with little warning, with patches sent by email to tz@iana.org rather than GitHub.
6. [PCRE2Project/pcre2](https://github.com/PCRE2Project/pcre2) (~1.4k Stars) - A BSD-licensed C library for Perl-compatible regular expressions with an optional JIT engine, which the project says is bundled in products from Excel and Safari to Apache and Git.
7. [harfbuzz/harfbuzz](https://github.com/harfbuzz/harfbuzz) (~6.2k Stars) - The text shaping engine the project says shapes the majority of text on modern screens, named from Persian harf (letter) and buzz (open) as a calque of OpenType.
8. [ImageMagick/ImageMagick](https://github.com/ImageMagick/ImageMagick) (~17.8k Stars) - The image conversion suite that the title text of xkcd 2347 jokes will one day break for good; its README urges you to write a security policy for your environment before using it.

### 🔧 Quiet Workhorses

9. [libuv/libuv](https://github.com/libuv/libuv) (~27.3k Stars) - An MIT-licensed asynchronous I/O library built primarily for Node.js and also used by Julia, Luvit and uvloop, with one event loop over epoll, kqueue, IOCP and event ports.
10. [RsyncProject/rsync](https://github.com/RsyncProject/rsync) (~5.3k Stars) - The file copier that sends just the differences between files across the link, shipped with the technical report describing its delta-transfer algorithm.
11. [tmux/tmux](https://github.com/tmux/tmux) (~50.0k Stars) - An ISC-licensed terminal multiplexer whose sessions keep running after you detach, built for OpenBSD, FreeBSD, NetBSD, Linux, macOS and Solaris; its README says bug reports and especially code contributions are most welcome.
12. [git/git](https://github.com/git/git) (~64.1k Stars) - Originally written by Linus Torvalds and developed on its mailing list, not GitHub; this repo is a publish-only mirror, and GitGitGadget turns pull requests into list patches.

## 🏗️ Closing Thoughts

What stands out in this list is how plain the work is: Munich paying for six months of libexpat upkeep, jq's new team shipping a release after five quiet years, zlib's README still asking someone to write man pages, tz's contributors emailing rule changes with sources. Nothing heroic, just sustained attention. The xz incident is the reminder that trust is a security control too, since a stranger spent two years earning it. More helping hands, not more blame, is the fix.

Here is the short list. Pay: [curl takes donations](https://curl.se/donation.html) through Open Collective, [Git takes them through the Software Freedom Conservancy](https://git-scm.com/sfc), [ImageMagick takes GitHub Sponsors](https://github.com/sponsors/ImageMagick), and companies can fund SQLite through its [Consortium](https://sqlite.org/consortium.html). Report well: curl ended its bug bounty in January 2026, citing a surge of AI-generated slop reports and a confirmed-vulnerability rate below one in twenty, so a verified, reproducible report is a real gift. Send fixes upstream instead of carrying a private patch, but read the rules first: Git wants patches on its mailing list, tz wants plain email with sources, and SQLite wants a public-domain affidavit.
